AZTRAWEB — revisi terbatas contoh proyek
==========================================
Basis: file website asli.

Perubahan yang dilakukan hanya pada contoh proyek:
- NEXORA diganti menjadi RAKUIN pada gambar preview dan kartu proyek.
- Gambar proyek RAKUIN dipasang pada kartu.
- Tombol "Request konsep ini" tetap ada dan tetap menggunakan mekanisme JavaScript website.
- Fitur "Ajukan request khusus", navigasi, layanan, harga, kontak, About, dan bagian lain tidak dihapus.
- Tidak menambahkan bagian informasi proyek baru.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ini di VS Code.
3. Jalankan index.html dengan Live Server.
4. Jangan pisahkan file gambar dari index.html.
