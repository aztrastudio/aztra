AZTRA — Revisi tombol request KOPI RUANG dan RAKUIN

Isi folder ini: index.html, style.css, script.js, dan aset gambar yang diperlukan.

Cara pakai GitHub Pages:
1. Download dan ekstrak ZIP ini.
2. Buka repository GitHub AZTRA.
3. Unggah/ganti file index.html, style.css, script.js, aztra-logo.png, portfolio-kopi-rakuin.png, dan project-rakuin.png dengan file dari folder ini.
4. Commit changes pada branch main.
5. Tunggu GitHub Pages memperbarui website lalu refresh.

Fungsi tombol Request konsep ini akan mengisi formulir konsultasi sesuai konsep KOPI RUANG atau RAKUIN. CSS tetap menggunakan file style.css yang disertakan.
